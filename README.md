# Sballato 🎲⚔️

**Sballato** — многопользовательская 2D браузерная RPG в пиксель-арт стилистике с синхронными карточными дуэлями в реальном времени (**Card Clash**).

---

## 🎮 Ключевые особенности

* **2D Top-Down Мир:**
  * Таверна «Хитрый Туз» — общий хаб для игроков и NPC.
  * Нативная интеграция спрайтов и анимаций из **Aseprite**.
  * Свободное перемещение (`WASD` / стрелки) с коллизиями стен и столов.

* **Боевая система Card Clash (RPG-Блэкджек):**
  * **Синхронный бой 1v1:** оба игрока тянут карты и разыгрывают способности одновременно.
  * **Нарастающий темп:** 
    * Раунд 1: 60 сек, кулдаун 2.5 сек
    * Раунд 2: 45 сек, кулдаун 1.75 сек
    * Раунд 3 (финал): 30 сек, кулдаун 1.0 сек
  * **Числовые карты (1–3):** плавное приближение к 21.
  * **Карты способностей (до 3 в руке):** атака ($+3$, $+5$), поглощающие щиты ($3$ ед. защиты), отражение «Зеркалом», сброс и заморозка кулдауна оппонента.
  * **Правило перебора (Bust):** при счете $>21$ очки сбрасываются до $0$, и накладывается стан на 3 секунды.

* **Мета-прогрессия «Удача» (Luck):**
  * Победитель матча крадет валюту и $+2$ очка «Удачи» у побежденного.
  * Высокая удача повышает шанс вытянуть карту способности и выпадение точного числа для сбора 21.

* **Система ролей (RBAC) и Гильдии:**
  * 👑 **ГМ (Game Master):** полное управление игрой, режим Бога в дуэлях, подкрутка удачи (0–1000), спавн карт и редактирование файлов игры.
  * 🛡️ **Администратор частного сервера:** модерация комнат, пароли, кик/бан, настройка правил столов.
  * ⚔️ **Глава гильдии:** управление кланом и доступ к **«Банку карт гильдии» (Guild Vault)** — каждый участник может взять 1 карту из хранилища в свой пул дуэли.
  * 🎲 **Обычный игрок:** дуэли, квесты, прокачка.

---

## 🛠️ Стек технологий

* **Frontend:** Next.js (App Router), React 19, Tailwind CSS, TypeScript
* **Игровой движок:** Phaser 3 (HTML5 Canvas / WebGL)
* **Сеть и мультиплеер:** Node.js, Express, Socket.io (WebSocket в реальном времени)
* **Графика:** Aseprite (Spritesheets + JSON Data) + Tiled (карты локаций)

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера разработки
```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
